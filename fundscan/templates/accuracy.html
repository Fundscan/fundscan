How this is measured

For every exchange/symbol pair, we compare its current headline net APY against the simple average of its net APY over the same {{ window_days }}-day window, using the same funding snapshots the scanner already stores every cycle. The gap between those two numbers is the measure above.

This is an arithmetic mean, not a time-weighted average — it only approximates one when snapshots are evenly spaced, which is the normal case. A gap in data collection (fetcher downtime, a pruned range) would skew a pair's average slightly, since a sparser period counts the same as a dense one.

The snapshots behind this page record the flat-fee net APY, not a position-sized value — order book history isn't persisted, so this reflects realized rate reality, not realized slippage at a specific trade size. For that, see the per-instrument breakdown on the live board, which shows net yield at your chosen position size today.
